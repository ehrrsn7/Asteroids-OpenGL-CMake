
# Asteroids OpenGL CMake

This project uses OpenGL, GLFW, and GLAD. On Windows, you need a C++ toolchain, GLFW, and the DLLs available at runtime.

## Quick start (Windows)

```powershell
winget install --id Kitware.CMake --scope user -e
winget install --id BrechtSanders.WinLibs.POSIX.UCRT --scope user -e
winget install --id MSYS2.MSYS2 --scope user -e
```

Then, in the MSYS2 shell:

```bash
pacman -Syu --noconfirm
pacman -S --noconfirm mingw-w64-ucrt-x86_64-glfw
```

Then from the project folder:

```powershell
$env:Path = "$env:USERPROFILE\AppData\Local\Microsoft\WinGet\Packages\BrechtSanders.WinLibs.POSIX.UCRT_Microsoft.Winget.Source_8wekyb3d8bbwe\mingw64\bin;" + $env:Path
$env:CMAKE_PREFIX_PATH = 'C:\msys64\ucrt64;C:\msys64\mingw64;' + $env:CMAKE_PREFIX_PATH
cmake -B build -G "MinGW Makefiles"
cmake --build build --config Debug
.\build\Asteroids.exe
```

## Windows setup

The following steps were verified on Windows and are the minimum needed to build and run this project.

### 1. Install the required tools

Open PowerShell and install:

```powershell
winget install --id Kitware.CMake --scope user -e
winget install --id BrechtSanders.WinLibs.POSIX.UCRT --scope user -e
```

You will also need MSYS2 so GLFW can be installed from its package repository:

```powershell
winget install --id MSYS2.MSYS2 --scope user -e
```

### 2. Install GLFW

Open the MSYS2 shell and install GLFW:

```bash
pacman -Syu --noconfirm
pacman -S --noconfirm mingw-w64-ucrt-x86_64-glfw
```

### 3. Configure the project with MinGW

From the project folder, run:

```powershell
$env:Path = "$env:USERPROFILE\AppData\Local\Microsoft\WinGet\Packages\BrechtSanders.WinLibs.POSIX.UCRT_Microsoft.Winget.Source_8wekyb3d8bbwe\mingw64\bin;" + $env:Path
$env:CMAKE_PREFIX_PATH = 'C:\msys64\ucrt64;C:\msys64\mingw64;' + $env:CMAKE_PREFIX_PATH
cmake -B build -G "MinGW Makefiles"
```

If you already configured the project for Visual Studio before, delete the old build directory first:

```powershell
Remove-Item -Recurse -Force build -ErrorAction SilentlyContinue
```

### 4. Build and run

```powershell
cmake --build build --config Debug
.\build\Asteroids.exe
```

### 5. Runtime note

The executable requires the GLFW runtime DLL to be available. The MSYS2 install places it in the MSYS2 runtime folders, so if you get an error about `glfw3.dll` not being found, make sure the relevant MSYS2 binary directory is on your `PATH` (for example, `C:\msys64\ucrt64\bin`).
